# **ToolShop-Demo Website Testing**

## **Project Overview**

ToolShop Demo is an e-commerce web application that simulates an online shopping experience. Users can register, sign in, browse products, view product details, add items to the shopping cart, proceed through checkout, enter billing information, select a payment method, and complete an order. The application also includes contact form functionality. This project involves both manual and automation testing to validate key e-commerce workflows through positive and negative test scenarios. Manual testing is performed to verify application functionality, usability, and input validations, while automation testing is implemented using Java, Selenium WebDriver, TestNG, Apache POI, and the Page Object Model (POM) to improve test efficiency, reusability, and maintainability.

## **Automation Framework**

The ToolShop Demo automation project is built using Java, Selenium WebDriver, TestNG, Maven, and the Page Object Model (POM). TestNG manages test execution 
and assertions, while Maven manages project dependencies and can run the test suite.

POM separates webpage interactions from test logic. Each page class represents a page or functional area of the application.
