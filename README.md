**ToolShop-Demo Website Testing**

**Project Overview**

ToolShop Demo is an e-commerce web application that simulates an online shopping experience. Users can register, sign in, browse products, view product details, 
add items to the shopping cart, proceed through checkout, enter billing information, select a payment method, and complete an order. The application also includes 
contact form functionality. This project is used to automate and validate key e-commerce workflows, including positive and negative scenarios, using Java, 
Selenium WebDriver, TestNG, Apache POI and the Page Object Model (POM).

**Automation Framework**

The ToolShop Demo automation project is built using Java, Selenium WebDriver, TestNG, Maven, and the Page Object Model (POM). TestNG manages test execution 
and assertions, while Maven manages project dependencies and can run the test suite.

POM separates webpage interactions from test logic. Each page class represents a page or functional area of the application.
